# Changelog

## 0.1.0 — 2026-08-22

Initial pre-implementation artifact package.

- Reframed the project as an executable browser-host conformance study rather than a browser product.
- Froze reference chrome v0 and sixteen scenario-level oracles.
- Defined protocol envelope, methods, events, error model, capability negotiation, temporal semantics, and canonical state.
- Required paired raw and normalized evidence with explicit suppression records.
- Added evidence, trace, protocol, and finding schemas.
- Added mock, WebKitGTK, and servo-gtk adapter boundaries.
- Added four release waves, rollback boundaries, risk controls, decision records, and agent prompts.
- Permanently excluded browser-product features and WebExtension execution from this project.
